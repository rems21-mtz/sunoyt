                              Changes

                                Integration ?

                                ?

                                Adds Creator Toolkit's controls to suno.com itself, beside Suno's own.

                                Download button

                                A download button on every song on suno.com, yours and public ones, that does not count against Suno's download limit. Songs are saved in the format you choose below.

                                Bulk Generate button

                                Bulk generates your song many times with sliding Weirdness and Style Influence values, so you find the best version faster. Set how many songs and how far the values slide below.

                                Style Search button

                                Swaps the styles in Suno's Styles box for the ones the most popular songs in that style use. Suno's own undo button brings yours back.
